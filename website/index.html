Recommended for your computer

FlixView for Windows

Windows 10 and 11 · 64-bit installer

Download for Windows

FlixView-Setup-0.1.20.exe

  1. Open the installer once it has downloaded.
  2. If Windows says "Windows protected your PC", choose More info, then Run anyway. FlixView is not code-signed yet, so Windows does not recognise it.
  3. Follow the installer. FlixView opens when it finishes and keeps itself up to date.
Recommended for your computer

FlixView for macOS

Apple Silicon (M1 and newer) · disk image

Download for macOS

FlixView-0.1.20-arm64.dmg

  1. Open the disk image and drag FlixView into Applications.
  2. If macOS says FlixView "is damaged" or "cannot be opened", it is because FlixView is not notarised by Apple yet. Open Terminal and run: xattr -cr /Applications/FlixView.app
  3. Open FlixView from Applications. You only need to do this once.
Recommended for your computer

FlixView for Linux

AppImage · most 64-bit distributions

Download for Linux

FlixView-0.1.20.AppImage

  1. Make it executable. Right-click it, open Properties and allow it to run as a program, or run: chmod +x FlixView-*.AppImage
  2. Double-click it to launch. No installation needed.
  3. Not starting on a newer distribution? Install libfuse2 (on Ubuntu 22.04 and later: sudo apt install libfuse2).

Older versions and release notes are on GitHub.

Questions

Good to know.

Something else? Ask on GitHub.

Is FlixView really free?

Yes. FlixView is free and open source under the MIT licence, with no subscriptions, accounts or in-app purchases. You can support the project if you enjoy it, but you never have to.

How do updates work?

FlixView checks for a new version every time it starts and every 30 minutes while it is open, then asks before installing. Updating never touches your watchlist, favourites or history.

Where is my data stored?

On your own computer, in FlixView's app data folder. Nothing goes to an account or a cloud server. Settings has buttons to open that folder and to export or import a backup.

Does it work on Intel Macs?

The macOS version is built for Apple Silicon (M1 and newer). There is no Intel build at the moment.

Why does my computer warn me when I install it?

FlixView does not have a code-signing certificate yet, so Windows SmartScreen and macOS Gatekeeper do not recognise the publisher. The source code is public on GitHub, and every installer is built there automatically. The download section shows how to open it.

Is there a phone or TV app?

Not yet. FlixView is a desktop app for Windows, macOS and Linux.
